## 📝 Descripción del Proyecto
Este proyecto consiste en una **web informativa a modo bibliográfico** sobre la legendaria banda de Liverpool, **The Beatles**. El sitio recorre su trayectoria, los integrantes que marcaron una época y su legado musical. 

Fue desarrollado como trabajo práctico, aplicando los estándares de maquetación web aprendidos durante la cursada.
